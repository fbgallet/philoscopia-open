# Qualia

Les qualia sont les qualités vécues d'une expérience : le rouge tel qu'on le voit, la douleur telle qu'elle fait mal, le goût du café. Le mot désigne « l'effet que cela fait » d'être dans un état mental, par opposition à sa description physique. Toute la difficulté tient à ce qu'ils semblent accessibles à une seule personne : on peut mesurer une longueur d'onde, non le rouge que voit quelqu'un. Pour les uns, ils sont ce qu'aucune science du cerveau n'atteindra jamais, et signent les limites du [matérialisme](../glossary/materialism.md) ; pour les autres, une illusion que l'introspection se fait sur elle-même.
