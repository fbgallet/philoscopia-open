# Vijñaptimātra (rien-que-représentation)

Thèse centrale du [Yogācāra](../movements/yogacara.md) : ce que nous prenons pour des objets extérieurs n'est que représentation dans la conscience. Son sens est discuté, idéalisme métaphysique ou analyse de ce qui se donne dans l'expérience.
