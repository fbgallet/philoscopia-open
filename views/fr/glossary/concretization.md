# Concrétisation

*Concept propre à [Gilbert Simondon](../philosophers/simondon.md)*

Chez [Simondon](../philosophers/simondon.md), le processus par lequel un objet technique évolue d'un état abstrait, où chaque pièce remplit une seule fonction et où les éléments se gênent, vers un état concret, où chaque structure remplit plusieurs fonctions et où les éléments deviennent solidaires. Dans le moteur thermique, les ailettes de la culasse, d'abord ajoutées pour le refroidissement, finissent aussi par la renforcer mécaniquement : une même structure remplit deux fonctions. Ce n'est pas un simple gain de rendement : c'est une cohérence interne croissante, qui rapproche l'objet technique du mode d'existence de l'objet naturel sans l'y confondre.
