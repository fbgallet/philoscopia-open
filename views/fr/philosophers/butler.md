# Butler

*1956 – ? · Américaine · [Philosophie féministe](../movements/feminist-philosophy.md)*

Philosophe américaine dont Trouble dans le genre (1990) soutient que le genre n'exprime aucune essence mais se produit dans la répétition des actes ; une référence des études de genre.

> Profil embryonnaire : seule cette mini-fiche existe pour l'instant, les positions sourcées sur les axes restent à rédiger. Contributions bienvenues.

## Influencé par

- **[Foucault](../philosophers/foucault.md)** (réinterprète) : [Butler](../philosophers/butler.md) applique au genre l'analyse de [Foucault](../philosophers/foucault.md) : le pouvoir ne se contente pas de réprimer des identités données, il les produit. Le sexe lui-même, loin d'être une base naturelle, devient un effet des normes qui prétendent seulement le décrire.
