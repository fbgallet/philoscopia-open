# The syntax-and-meaning argument

*Argument for [Can a machine think](../axes/machine-mind.md) : Not by program alone*

**A program handles only forms; understanding is reaching a meaning. No quantity of rules crosses that gap, which does not condemn every artifact.**

*[Searle](../philosophers/searle.md), *"Minds, Brains, and Programs"*, 1980*

## The argument

1. A program is defined entirely by **syntax**, that is, by the shape of its symbols: one runs it correctly by following rules that speak only of the figure and place of signs, never of what they designate. That is exactly what lets one and the same program run on any machine.
2. But understanding is not handling signs, it is knowing what one is talking about, reaching the **semantics** and not the syntax alone: the signs must relate to something other than themselves, which is called [intentionality](../glossary/intentionality.md). A system that has only form at its disposal has, of itself, no way of reaching meaning, and adding rules changes nothing, since they are still rules about forms.
3. It will be objected that a simulation, if perfect, comes to the same thing. But **simulating** is not **reproducing**: the simulation of a storm wets no one, that of a digestion feeds no one. There is no reason to make an exception for understanding.
4. The brain, however, genuinely does produce thought: it therefore does not merely run a program, it has **causal powers** of its own, belonging to what it is and not only to what it computes. Nothing forbids an artifact from possessing them one day, but it will have to reproduce them, not simulate them.

**⇒** So running a program will never be thinking, without thought being the privilege of the living: what our machines lack is not life, it is the causal powers of the brain, or a body's engagement with a world.

## Deepenings

### Simulating and reproducing

*No one confuses the map with the territory, except where mind is concerned.*

1. A simulation reproduces the description of a process, not the process: the weather model that forecasts rain contains not one drop of water, and no one is surprised.
2. If this is granted for storms and digestion, one must say why thought would be the exception: either because it is nothing but a formal structure, which is precisely the thesis at issue, or by a privilege granted for no reason.

**⇒** Taking the simulation for the thing itself already assumes that thought is nothing but form.

### Intelligence without a body

*The other road to the same middle: grasping a situation takes a body that inhabits it, not a stock of rules.*

1. Grasping a situation is not running through a list of its features: it is seeing at once what, in this context, deserves attention, a sense of **relevance**. A child knows one does not joke at a funeral without ever having learned the rule.
2. That sense of relevance cannot be put into rules, since a rule would be needed to choose the rule, and so on endlessly. It rests on a know-how acquired by a body that deals with the world, that needs, that moves, that fears.
3. Dreyfus, drawing on [Merleau-Ponty](../philosophers/merleau-ponty.md), concludes not that the machine is impossible, but that the disembodied machine is: an artifact engaged in a world would not fall under the objection.

**⇒** This route does not answer the [Chinese Room](../thought-experiments/chinese-room.md), from which it is independent: it reaches the same middle position by another road. What the program lacks is then not necessarily life: it is a body engaged in a world, which nothing forbids us to build.

*Dreyfus, *What Computers Can't Do*, 1972*
