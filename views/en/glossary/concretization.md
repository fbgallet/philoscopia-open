# Concretization

*Concept associated with [Gilbert Simondon](../philosophers/simondon.md)*

In [Simondon](../philosophers/simondon.md), the process by which a technical object evolves from an abstract state, in which each part fulfils a single function and the elements hinder one another, toward a concrete state, in which each structure fulfils several functions and the elements become interdependent. In the combustion engine, the fins on the cylinder head, first added for cooling, come also to reinforce it mechanically: one structure fulfils two functions. It is not a mere gain in efficiency but a growing internal coherence, which brings the technical object closer to the mode of existence of the natural object without merging with it.
