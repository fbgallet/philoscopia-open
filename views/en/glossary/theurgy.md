# Theurgy

*Concept associated with [Iamblichus](../philosophers/iamblichus.md)*

The set of rites by which late Neoplatonism sought to unite the soul with the gods. For [Iamblichus](../philosophers/iamblichus.md), it is not thought that binds us to the gods but sacred acts whose efficacy comes from them. [Proclus](../philosophers/proclus.md) ranks theurgy above philosophy, which [Plotinus](../philosophers/plotinus.md) had deemed sufficient for the ascent towards the [One](../glossary/the-one.md).
